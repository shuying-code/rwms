# rwms（Rust 仓库管理系统）用户操作手册

> 适用版本：v1.0.0 / v0.1.0 及以上。
> 本手册面向最终用户与管理员，介绍启动、登录、各业务模块操作、API 使用、数据与配置、常见问题。
> 快速总览见仓库根目录 [README](../README.md)；部署打包见 [DEPLOYMENT](../DEPLOYMENT.md)。

---

## 1. 简介

rwms 是一个用 **Rust + Axum + SeaORM** 编写的**本地化、单文件、零外部数据库依赖**的仓库管理系统（WMS）。
内嵌 **SQLite**，内置完整 Web 前端（HTML/CSS/JS）与 JWT 认证，**开箱即用、单二进制部署**，支持 Windows / macOS / Linux。

---

## 2. 安装与启动

### 2.1 直接运行

```bash
rwms                 # 启动服务（默认 0.0.0.0:8080）
```

启动时会在数据库目录创建 `wms.db` 并自动建表（首次启动自动完成建表与迁移）。

### 2.2 Windows 安装包

运行 `rwms-setup-*.exe` 按向导安装（可选桌面快捷方式 / 开机自启），安装后从开始菜单或桌面快捷方式启动。详见 [DEPLOYMENT](../DEPLOYMENT.md)。

### 2.3 容器

```bash
docker run --rm -p 8080:8080 -v rwms-data:/wms ghcr.io/shuying-code/rwms:latest
```

## 3. 访问与登录

1. 浏览器访问：<http://localhost:8080/login.html>
2. 默认账号：`admin` / `admin`（**生产环境请务必修改密码与 `JWT_SECRET`**）。
3. 登录成功后进入首页仪表盘，左侧/顶部菜单进入各业务模块。
4. 健康检查：<http://localhost:8080/health>（返回 `{"status":"UP"}`）。

---

## 4. 功能模块

系统内置以下页面（`static/`）：

| 页面 | 文件 | 说明 |
|---|---|---|
| 登录 | `login.html` | 账号登录获取 JWT |
| 首页 | `index.html` | 仪表盘总览 |
| 物资 | `material.html` | 物资列表 / 详情 / 新增 / 更新 / 删除（分页） |
| 分类 | `category.html` | 物资分类增删改查 |
| 仓库 | `warehouse.html` | 多仓库信息维护 |
| 供应商 | `supplier.html` | 供应商信息维护 |
| 客户 | `customer.html` | 客户信息维护 |
| 入库单 | `inorder.html` | 创建（含明细）/ 列表 / 详情 / 审核 / 删除 / 明细查询 |
| 出库单 | `outorder.html` | 创建（含明细）/ 列表 / 详情 / 审核 / 删除 / 明细查询 |
| 库存 | `stock.html` | 按多条件过滤 + 分页查询库存 |

### 典型业务流程

1. **基础数据**：先在「分类 / 仓库 / 供应商 / 客户」维护基础信息。
2. **物资建档**：在「物资」中新增物资（关联分类、单位等）。
3. **入库**：在「入库单」创建单头 + 明细 → 提交 → **审核（通过/拒绝）**，通过后增加库存。
4. **出库**：在「出库单」创建单头 + 明细 → 提交 → **审核**，通过后扣减库存。
5. **库存查询**：在「库存」按物资/仓库等条件筛选并分页查看。

## 5. 认证说明

- 登录：`POST /api/login` 获取 JWT；登出：`POST /api/logout`。
- 除公开路由外，所有接口需带请求头 `Authorization: Bearer <token>`，由中间件统一校验。
- **公开路由（无需认证）**：`GET /`、`GET /health`、`POST /api/login`。

## 6. API 概览（便于集成 / 脚本调用）

受保护路由需 `Authorization: Bearer <token>`：

| 资源 | 端点 |
|---|---|
| 登出 | `POST /api/logout` |
| 物资 | `GET/POST /api/materials`、`GET/DELETE /api/materials/:id`、`POST /api/materials/update` |
| 分类 | `GET/POST /api/categories`、`GET/DELETE /api/categories/:id`、`POST /api/categories/update` |
| 仓库 | `GET/POST /api/warehouses`、`GET/DELETE /api/warehouses/:id`、`POST /api/warehouses/update` |
| 供应商 | `GET/POST /api/suppliers`、`GET/DELETE /api/suppliers/:id`、`POST /api/suppliers/update` |
| 客户 | `GET/POST /api/customers`、`GET/DELETE /api/customers/:id`、`POST /api/customers/update` |
| 入库单 | `GET/POST /api/in-orders`、`GET/DELETE /api/in-orders/:id`、`POST /api/in-orders/audit`、`GET /api/in-orders/:id/items` |
| 出库单 | `GET/POST /api/out-orders`、`GET/DELETE /api/out-orders/:id`、`POST /api/out-orders/audit`、`GET /api/out-orders/:id/items` |
| 库存 | `GET /api/stocks` |

示例：

```bash
# 登录拿 token
curl -s -X POST http://localhost:8080/api/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin"}'

# 带 token 查询物资
curl -s http://localhost:8080/api/materials \
  -H "Authorization: Bearer <token>"
```

## 7. 配置

配置来自 `application.yml`（可用 `APP_ENV` 切换），常用环境变量：

| 变量 | 说明 |
|---|---|
| `PORT` | 监听端口（默认取 `application.yml` 的 `server.port`，即 8080） |
| `JWT_SECRET` | JWT 密钥（覆盖 `jwt.secret`，**生产必须设置**） |
| `APP_ENV` | 运行环境标识（dev / test / prod） |
| `RUST_LOG` | 日志级别过滤（如 `info`、`debug`） |

## 8. 数据库与数据目录

SQLite 文件 `wms.db` 由代码按平台决定：

| 平台 | 路径 |
|---|---|
| Windows | `C:\ProgramData\wms\wms.db` |
| Linux / macOS | `/wms/wms.db`（Docker 建议挂载卷到 `/wms`） |

日志文件与数据库同目录（`wms.log`，按天滚动）。

> 备份：直接复制 `wms.db`（及 `wms.log`）即可；恢复时替换回原目录。

## 9. 常见问题（FAQ）

**Q：需要安装数据库吗？**
不需要。内嵌 SQLite，首次启动自动创建 `wms.db` 并建表。

**Q：默认账号是什么？**
`admin` / `admin`。正式使用前请修改密码与 `JWT_SECRET`。

**Q：端口被占用怎么办？**
用 `PORT=9090`（或修改 `application.yml` 的 `server.port`）启动。

**Q：数据目录在哪？**
Windows 为 `C:\ProgramData\wms`，Linux/macOS 为 `/wms`。

**Q：如何停止服务？**
关闭程序窗口，或结束 `rwms` 进程。
